# 右手五指状态识别（OpenCV）

识别右手拇指、食指、中指、无名指、小指的伸开 / 收起状态。当前开发条件是背景变化较小、浅色矩形背景板、右手掌心大致朝向镜头。使用传统图像处理，不依赖深度学习或 MediaPipe。

根目录是当前识别版本，已同步背景板定位和近期手指识别修复。`end/` 保留此前独立的照片优化版，其算法没有同步本轮修复；查看当前效果请运行根目录 `main.py`。

## 安装与运行

在仓库根目录执行，已验证环境为 Windows / Python 3.11.9。需要带窗口功能的 `opencv-python`，不能只安装 headless 版本。

```powershell
python -m pip install -r requirements.txt

# 默认浏览 data/new 下的开发照片
python -B main.py
python -B main.py image new

# 非标准照片、历史照片
python -B main.py image nonstd
python -B main.py image old

# 测试视频：显式传入绝对路径
python -B main.py video "G:\python-project\opencv-new\project\qianrushi-shoushi\data\test\test1.mp4"

# 摄像头
python -B main.py camera
```

视频路径请按实际位置替换。仓库这一同步快照默认仍是照片输入；开发目录后续的视频默认输入设置与此分开。根目录照片入口按素材组选择，不接受任意照片路径；把自己的开发照片放进 `data/new/`，程序会自动枚举常见图片格式。

素材不随 Git 仓库提供。本机 `data/` 是指向开发目录素材的目录联接；新克隆仓库不会自动得到该联接或照片、视频，需要自行准备素材。运行识别不需要真值表、开发脚本或开发目录的 `codex/`。

## 当前处理流程

1. 从图像中的浅色区域及直线边缘定位背景板，允许手臂遮挡部分板边；定位不确定时回退原图。
2. 裁剪背景板区域，保留有效板面约束，再估计手臂方向并转正。
3. 在有效区域内进行肤色分割、掩膜清理与手掌重建。
4. 根据掌心、指尖、指缝、指轴以及短凸起轮廓判断五指身份和伸缩状态。
5. 输出识别结果，并显示掩膜、轮廓、指尖或背景板定位。视频模式还使用已有的时间稳定判定。

定位坐标由当前图像计算；运行识别时不读取照片编号对应的答案。算法仍包含几何阈值和位置先验，不能把“没有查答案”理解为已经证明对新人物、新场景都可靠。

## 验证结果与限制

当前开发照片按“五指身份和状态全部一致”统计：

| 素材 | 正确 / 有标签总数 |
| --- | --- |
| 当前开发照片 `data/new` | 51 / 52 |
| 历史照片 | 25 / 28 |
| 非标准照片 | 10 / 10 |

原照片测试集已按开发安排并入 `data/new`，上述均为开发素材结果，不是独立测试准确率。剩余开发错误为 `shot_26.png`：预期拇指、中指、小指，当前把小指判成无名指。视频尚无逐帧真值，不能报告准确率。

非标准素材的 10 / 10 表示五个二值状态匹配真值，并不代表恢复了被遮挡的五根完整手指。当前仍依赖可见轮廓；没有获得特征的手指默认收起，因此“不可见”与“确认弯曲”尚未区分。并拢、严重重叠、背手、左手、运动模糊和背景板定位失败均可能造成误判。

## FPGA 迁移

本仓库目前是电脑端软件参考，尚未实现 FPGA 硬件逻辑或机械手通信。板定位、旋转、连通区域、距离变换与轮廓处理需要另行评估缓存、带宽、定点化和流水线方案；Python 运行通过不能保证目标 FPGA 的资源和帧率满足要求。
